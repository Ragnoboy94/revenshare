# RevenShare — материалы для чата на сайте

**Версия:** 2.1  
**Дата:** 27 ноября 2026 года  
**Сайт:** https://revenshare.ru

## Что отвечает посетителю

Локальный чат на сайте читает **только**:

- `04_REVENSHARE_KNOWLEDGE.md` — публичные факты
- `05_SCENARIOS_AND_REPLIES.md` — готовые ответы

В этих двух файлах **не должно быть** служебных указаний вроде «не говори», «не обещай», «критически важно». Всё, что попадает в ответ, должно быть текстом для человека.

## Служебные инструкции (не для выдачи в чат)

- `01_SYSTEM_PROMPT.md` — роль и запреты
- `02_PERSONA_AND_TONE.md` — тон
- `03_DIALOGUE_FLOW.md` — логика диалога
- `06_HANDOFF_AND_LIMITS.md` — эскалация и ограничения
- `07_CHAT_UX_AND_CONTEXT.md` — UX виджета

Они лежат рядом для людей/будущей LLM-интеграции и **не подмешиваются** в ответы текущего локального матчера.

## Источник фактов

Сверено с публичной главной RevenShare: разделы «Как это работает», «Условия», «Кому подходит», FAQ и «Обсудить проект». При расхождении приоритет у договора и актуальных условий владельца проекта.
